# YouTube Script Writing (PYH-Scoped)

## Ràng buộc PYH (bắt buộc)
- Chỉ áp dụng cho viết hook, mạch dẫn (through-line) và payoff (**Checkpoint 3–5**).
- **Bỏ** `Checkpoint 2` tự tìm nguồn/Shock Score (PYH dùng `evidence/ledger.yaml` & `expert-brief.md` có sẵn), bỏ khuyên "Restate complex ideas twice", bỏ `Checkpoint 7` Binge Loop hứa hẹn video sau, và **không dừng hỏi duyệt từng checkpoint** trong bước chạy batch.
- Giữ một tầng chính (TOFU/MOFU/BOFU) phù hợp câu hỏi; không nhồi CTA bán hàng hay bịa trải nghiệm bác sĩ.

## Core Psychology

- **Expectations vs. Delivery**: Title/thumbnail/hook set one clear promise; the script must pay off that exact promise with verified evidence.

## Checkpoint 3: Write the Hook (0–15s)

1. **Alignment**: Spoken hook, on-screen visual, and title address the same question immediately.
2. **Speed**: Signal real value within the first 3 seconds—no throat-clearing ("Chào mừng các bạn quay lại kênh...").
3. **Clarity & Curiosity**: Open one honest question or tension that the approved claims actually answer.

## Checkpoint 4: Choose Story Structure & Outline

- Sequence chapters in `script/outline.yaml` so each chapter goal advances the answer (context → mechanism → real-world consequence → safe action).
- Cut tangents, textbook definitions, and repetitive summaries that stall progression.

## Checkpoint 5: Write the Body

- For each section, pair **what happens** (mechanism) with **why it matters** (practical consequence for the viewer) using verified claims only.
- Use natural transitions/rehooks between chapters to sustain attention without repeating earlier points.
- Verify flow by checking: does every paragraph add new value, keep sentences concise (≤ 32 words), and deliver a clear payoff before the standard channel outro?
